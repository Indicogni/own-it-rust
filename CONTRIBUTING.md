# Contributing

[Course overview](README.md)

Thank you for helping to make "Own It: Hands-On Mastery of Rust" more accurate. Corrections are very welcome.

## Report an error as an issue

If a test, a hint, a solution, a compiler message or a sentence is wrong or unclear, open an issue in the course repository on GitHub (the link is in the [README](README.md#licence-trademarks-and-errors)). One issue per problem is easiest to handle. Please include:

- **Where:** the file and the line, or the unit and lesson (for example "Chapter 5, lesson 03" or "M2, lesson 04").
- **What is wrong:** what the text or the test says, and what you expected instead.
- **Evidence:** for a claim about Rust, a link to the primary source (the standard library documentation, the Rust Reference, the Cargo book) or a short program that shows the behaviour.
- **For a test or a tool:** your operating system and processor, the output of `rustc --version` and `cargo --version` run inside the repository, the exact command you ran, and its full output as text (not a screenshot).
- **For a test that rejects your solution:** your solution of that lesson, if you believe it is correct. For a checkpoint or the final assessment, describe the problem instead of pasting a solution, because issues are public.

## Pull requests

Pull requests cannot be merged yet. Before text or code from outside can become part of the course, a contributor agreement must be published here, and there is none yet. Until then, please open an issue instead, even for a one-word fix. You may describe the exact change you suggest in the issue.
